# 念头

先判断值不值得焦虑，再把应对封死在三套。

**手机打开：** [https://mikefan1433.github.io/anxiety-thoughts-collector/](https://mikefan1433.github.io/anxiety-thoughts-collector/)

「念头」是一个给过度思考者用的**结构化笔记本**：念头来的时候，强制你先分流（真问题 vs 自己吓自己），再写下恐惧、影响范围、恰好三套预案，并看见那些你控制不了的事被划掉。结果出来后可以回填；你曾经熬过来的经历，放在独立的「过关清单」里，下次焦虑时随时打开。

> 我的一生都充满了不幸，但其中大部分都未发生过  
> —— 法国作家蒙田

**这不是医疗产品，不能替代心理咨询、诊断或危机干预。**

---

## 它解决什么

焦虑念头出现时，人很容易演最坏剧本、停不下来，也分不清这是不是真问题。普通备忘录太散；完整 CBT 长表又太重，忙起来根本填不完。

「念头」只做一件事：在工位或夜里，用几分钟走完一条有上限的回路——该停就停，该推进就把 Plan A / B / C 写死。

适合：日程紧、容易灾难化、缺少稳定倾诉对象、愿意写字但需要结构的人。

不适合：只想打心情卡或冥想的人；需要紧急临床帮助的人。

---

## 功能

- **记下念头**：先问「当下能否逐步推进」——不能推进算成功停手（仍留一条轻量记录）；能推进则继续拆解。
- **恐惧与范围**：写下脑补的最坏结果（1–5 条）和发生概率；选择影响范围（今晚情绪 / 本周安排 / 身份与长期后果）。
- **恰好三套思路**：Plan A 最优、Plan B 小状况时的平替、Plan C 搞砸了大不了怎么办。没有第四套。
- **Review**：把无法控制的变量打红叉，提醒你不必扛这些。
- **已有念头**：列表不堆在首页；可按全部 / 推进中 / 内耗 / 已有结果筛选；随时改字段、回填真实结果（相对当时担心：更糟 / 差不多 / 更好）。
- **过关清单**：记录「发生前怕什么 → 中途怎么熬 → 最后怎样了」（允许不完美）；已有结果的念头也可收入过关，不重复生成。
- **中 / EN**：顶栏随时切换。
- **备份与恢复**：导出 JSON 到本机，清浏览数据后可再导入。

## 快速开始

需要 [Node.js](https://nodejs.org/) 18+。

```bash
git clone https://github.com/MikeFan1433/anxiety-thoughts-collector.git
cd anxiety-thoughts-collector
npm install
npm run dev
```

浏览器打开终端提示的地址（一般为 `http://localhost:5173`）。

- 桌面：页面以约 390px 的笔记本画框展示（按手机使用来设计）。
- 手机浏览器：铺满屏幕。

首次打开会有几条示例念头和过关记录，方便你看清结构；可以删掉，换成自己的。

本地预览生产构建：

```bash
npm run build
npm run preview
```

**手机长期使用：** 打开 [https://mikefan1433.github.io/anxiety-thoughts-collector/](https://mikefan1433.github.io/anxiety-thoughts-collector/) 。关掉页面再打开，记录仍在该手机浏览器里。重要内容请偶尔导出备份。

也可以把 `npm run build` 生成的 `dist/` 放到任意静态托管。**没有账号、没有服务器、没有云同步。**

## 怎么用

1. 点 **记下念头**。
2. 先判断：这是当下可以逐步推进的问题吗？（不是「今晚必须彻底解决」。）
3. 若只是吓唬自己：停在成功页，可选留一句，保存后结束。
4. 若可以推进：写契机与念头 → 恐惧与概率 → 影响范围 → Plan A/B/C → 不可控变量 → 确认保存。
5. 事后在 **已有念头** 里回填结果；值得留下的，点 **记录到过关清单**。
6. 焦虑再来时，打开底栏 **过关清单**，看自己曾经怎样怕过、又怎样过来。

重要记录请定期点右上角 **备份与恢复 → 导出记录到本地**。数据只存在当前浏览器，清网站数据、换浏览器或换设备都不会自动带走。

## 数据与隐私

- 记录保存在你这台设备的浏览器 `localStorage` 里，**不会上传到任何服务器**（本仓库也没有后端）。
- 导出的 JSON 含念头与过关全文，请当作私人文件保管。
- 导入会**替换**当前全部记录，导入前请确认文件来源。

## 技术

Vite 7 + React 19 单页应用。协议规则（分流、表单闸门、筛选、备份校验）在 `src/protocol.js`，与界面分开，便于测试。

```bash
npm test          # 协议与主路径冒烟
npm run build     # 生产静态资源
```
